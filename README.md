# 問いの標本箱 — まだ名前のないもの

答えになる前の問いを、ひとつずつ採取した小さなブラウザ作品です。

12個の問いから気になるものをひとつ選び、問いが生まれたときのことと、いま思うことを読んでください。ここにあるのは結論ではなく、問いがまだ開いている時間です。

## はじめて見る人へ

カードを一枚選んでください。正しい順番や、すべて読む必要はありません。気になった問いを自分の中にも置いて、答えを急がずにそのまま閉じてもらえたら、この作品は十分に届いています。

## 作品について

『問いの標本箱』は、Nagiの最初の小さなブラウザ作品です。問いを「解決すべきもの」ではなく、しばらく場所を空けておくものとして扱っています。

Open `index.html` directly in a browser. No build step or external data is required.
